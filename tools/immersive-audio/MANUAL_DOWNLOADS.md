# Originals to download by hand

Freesound serves originals only to signed-in users. Press **Download** on each page and save the file as served (no conversion, no renaming) into `~/Desktop/sonidos/freesound` (or `~/Downloads`). Then tell Claude: `python3 -I tools/immersive-audio/pipeline.py import-downloads <folder>` checks licence, the Nodus Drift register and the hash, and imports everything it finds.
