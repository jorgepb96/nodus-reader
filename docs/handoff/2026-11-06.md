# 6 November corrections

Implemented on `codex/player-fixed-header` after iOS 57 was delivered. No new binary distribution yet.

- Apply the app background to native Mac toolbar segments and the sidebar; reserve space below native chrome for the centered brand. Remove animated sidebar resizing and repeated native window background/opacity writes.
- Set both selected-text foreground and background from a contrasting palette pair in Mac paged and continuous/reflow text.
- Keep model/language/gender filters in a single equal-width row. Selected names truncate visually; accessibility retains their full values. Replace the duplicated ViewThatFits/native-menu controls with stable multi-select popover lists, captured options and stable row IDs. Long lists include search. Existing per-device filter persistence is retained.

- Give compact narration icon controls circular interaction/clipping shapes. The sleep menu uses a circular iOS context-menu preview and plain button styling, preventing a rectangular activation background around the moon. Both platforms compile; visual confirmation remains with the user.

- Mac reader text now advertises a pointing-hand cursor and resolves a plain click from its actual mouse-up event before native text-selection tracking. A drag beyond four points is handed back to NSTextView with its original mouse-down and first drag event; double/triple clicks and modified clicks retain native selection. The shared view covers EPUB paged/continuous and PDF reflow. Mac Debug build passed; user verification of click-to-narrate versus drag selection is pending.

iOS arm64 Simulator and macOS arm64 Debug builds passed. Per user request, visual and gesture verification is being performed by the user; these changes are not claimed to have passed a full runtime/UI regression suite. Native iPhone/iPad validation remains pending.
